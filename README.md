# Тесты сервера MCP (приватный репозиторий собирается из публичного «домика»)

Здесь **нет исходников**. Этот публичный репозиторий существует ровно для одного:
на публичных репозиториях стандартные раннеры GitHub **бесплатны и без лимита минут**
и дают **4 vCPU / 16 ГБ RAM**, тогда как приватным на Free достаётся 2 000 минут в месяц
и 2 vCPU / 8 ГБ.

Код читается из приватного репозитория по **deploy key** (только чтение, только один
репозиторий) и живёт на раннере лишь на время прогона.

Полное описание схемы, варианты и диагностика — в приватном репозитории:
`docs/отчёты-проверок/ПРОГОН-ТЕСТОВ-БЕЗ-КВОТЫ-инструкция.md`.

После прогона репозиторий и deploy key удаляются.
